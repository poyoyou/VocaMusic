# VocaMusic
spin-off project of stand2music, this project is focused on vocaloids instead of stands

# How to use
open the vocamusic executable<br>
click the reroll button
and you'll recieve a random music that is singed by a vocaloid<br>
when you click reroll, a random album is selected, the image of the album is showed and the music is played in the background.

# Requirements
